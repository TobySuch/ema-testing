# cards-icon

Custom **cards** block. Purpose: Grid of dark bordered cards with an icon, title and description, each linking to an item.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: icon cell (image, :icon: or emoji) | body cell (title, usually linked, then description). The first link in the row becomes the link for the whole card.

## Supported variations

No variations.
