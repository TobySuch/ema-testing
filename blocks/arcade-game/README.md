# arcade-game

Custom **custom** block. Purpose: Placeholder panel for an interactive arcade game, linking to the playable game on tobysuch.uk.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = game key/name (e.g. chess, countdown-numbers); row 2 (optional) = short description; row 3 = link to play the game on the original site (e.g. https://www.tobysuch.uk/arcade/chess/). Optional label cells (game | ..., description | ...) are accepted.

## Supported variations

No variations.
